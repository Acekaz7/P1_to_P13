# P1 – Project Folder and Terminal Navigation

## Aim

To create a portfolio project folder and practise basic terminal navigation commands.

## Commands

Run these commands in the terminal:

```bash
pwd
mkdir P1_to_P13
cd P1_to_P13
mkdir style css
touch index.html
touch style.css
ls
cd css
pwd
cd ..
```

## Description

- `pwd` displays the current working directory.
- `mkdir P1_to_P13` creates a new folder named P1_to_P13.
- `cd P1_to_P13` moves inside the P1_to_P13 folder.
- `mkdir images css` creates two folders named images and css.
- `ls` shows the contents of the current folder.
- `cd css` moves inside the css folder.
- `pwd` displays the current location in the terminal.
- `cd ..` moves one folder back to P1_to_P13.

## Result

The P1_to_P13 folder was successfully created with images and css subfolders. Basic terminal navigation commands were also practised.
